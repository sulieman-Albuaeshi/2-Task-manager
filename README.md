# Task Manager

A simple task manager built with vanilla **HTML, CSS, and JavaScript**, using **IndexedDB** to store tasks in the browser.

This project is part of the **Programming Advices roadmap**, built as practice for working with the DOM, forms, and client-side storage.


## 🎥 Demo
https://github.com/user-attachments/assets/2f120b35-cd41-4165-bb22-dc1a27ecc930

## Features

- Add tasks with a required title and an optional description (up to 300 characters)
- Pending tasks are shown in yellow, completed tasks in green
- Filter tasks by **All**, **Pending**, or **Done**
- Live search across titles and descriptions
- Live counters for total, pending, and done tasks
- Tasks are saved in the browser with **IndexedDB**, so they are still there after a refresh
- **Seed** button to load sample tasks and **Clear All** to remove everything
- Form validation for the required title
- Press `Ctrl` + `Enter` to add a task quickly

## What I Practiced

- DOM manipulation and event handling
- Form validation
- Filtering and searching data
- Storing and reading data with IndexedDB
